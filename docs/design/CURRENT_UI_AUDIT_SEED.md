# Current UI Audit Seed

Current screenshot:

`docs/design/references/current/projects-settings-before.png`

Known problems visible in the supplied screenshot:

- nested bordered surfaces dominate the hierarchy;
- two projects are presented as very large expanded blocks;
- blue, green, and orange compete as accents;
- «Добавить проект», «Загрузить документы», «Настроить ИИ агента»,
  and «Удалить проект» compete visually;
- destructive action is too prominent;
- documents and agent setup are placed side by side without a clear
  sequential setup model;
- large empty areas do not create airiness because the heavy borders and
  controls still make the screen feel dense;
- there is no compact portfolio overview;
- the screen does not visually explain the Control Plane value:
  delivery health, approvals, active runs, and process flow.

Codex must verify these observations against the actual running app and
cite concrete files/components before proposing changes.
