# Загрузка при ручном создании проекта

1. Загрузить 01-passport-specification.md как паспорт и ТЗ.
2. Загрузить 02-architecture.md как архитектуру.
3. Подготовить компактный контекст и применить к проектному Hermes.

Это требования/архитектура, не копия текущей доски. Company-level QA описан
как предложение, окончательное решение фиксируется в текущей задаче до запуска.
Активную работу переносим один раз после ручного создания проекта со ссылками
на GitHub. Завершённую историю и старые переписки не переносим.
Токены/пароли/ключи сюда не вставлять. Telegram настраивается отдельно,
клиентский канал этому проекту не нужен.
